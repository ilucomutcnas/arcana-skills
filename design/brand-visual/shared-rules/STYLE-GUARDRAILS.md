# Brand Visual Style Guardrails

These shared rules align all mini-skills in `design/brand-visual` around coherent brand expression, disciplined visual systems, and production-safe asset handling.

## 1) Keep brand consistency explicit and reproducible
- Start outputs with the intended brand tone (e.g., precise, playful, technical, premium) in concrete visual terms.
- Map tone to repeatable elements: spacing density, corner language, image treatment, icon style, and composition rhythm.
- Preserve consistency across variants (campaign, social, packaging, deck) unless divergence is intentionally requested.
- Call out when existing brand standards are unknown and treat assumptions as provisional.

## 2) Enforce typography and color discipline
- Specify type hierarchy (display, heading, body, caption) with role-based intent.
- Limit active type families and avoid ornamental mixing that dilutes identity.
- Define color roles (primary, secondary, accent, neutral, status) rather than isolated swatches.
- Use controlled contrast and saturation ranges to preserve legibility and brand character.

## 3) Track asset provenance and usage context
- Identify asset source class: client-supplied, licensed library, generated concept, or stand-in.
- Maintain provenance notes in handoff text so teams can replace stand-ins safely.
- Treat unknown provenance as unresolved input, not approved production material.
- Avoid legal conclusions; provide operational handling guidance instead.

## 4) Preserve prompt-to-visual traceability
- When visual direction comes from prompts, record key prompt constraints that materially shaped output.
- Distinguish fixed brand constraints from experimental creative choices.
- Make rationale reviewable: why this palette, layout, texture, or treatment supports the brief.
- Ensure revisions can be replayed without reinterpreting ambiguous style language.

## 5) Match output format to intended use
- Define destination context early: web hero, social tile, print ad, presentation, storefront, packaging mock.
- Tie dimensions, bleed/safe area, and resolution expectations to that context.
- Specify whether transparent background, layered source, or flattened export is required.
- Ensure file naming reflects campaign/version/channel for downstream clarity.

## 6) Use restrained visual emphasis
- Prioritize one dominant message per composition.
- Keep decorative effects (glows, gradients, textures, shadows) subordinate to hierarchy.
- Apply “premium” or “luxury” intent through spacing, material cues, and restraint, not ornament volume.
- Keep stylistic flourishes intentional and auditable against brand goals.

## 7) Safe handling of fonts and reusable assets
- Confirm font source class (system, licensed, brand-owned, temporary substitute).
- If a specific font is unavailable, document fallback with similar metrics and mood.
- Avoid embedding ambiguous third-party assets into final handoff without provenance notes.
- Separate exploratory mockups from production-ready asset sets.

## Quick pre-delivery checklist
- [ ] Brand tone is translated into concrete visual system rules.
- [ ] Typography and color roles are disciplined and consistent.
- [ ] Asset provenance status is documented.
- [ ] Prompt-to-output decisions are traceable.
- [ ] Format specs match destination channel.
- [ ] Decorative treatments do not overpower hierarchy.
- [ ] Font and asset handling notes support safe downstream usage.
