# Skill Catalog

## 1. library-architecture
- Use for API boundaries and responsibilities across prepare/layout/analyze flows, line-breaking contracts, bidi metadata, and migration risk.
- Use with: `browser-accuracy`, `corpus-diagnostics`, `architecture-review`.

## 2. development-workflow
- Use for setup assumptions, command selection, contributor loop, smoke checks, and review-ready branch hygiene.
- Use with: `demo-dogfooding`, `packaging-release`.

## 3. browser-accuracy
- Use for browser sweep planning, delta interpretation, blocking thresholds, snapshot refresh decisions, and regression triage.
- Use with: `library-architecture`, `corpus-diagnostics`.

## 4. benchmarks-profiling
- Use for benchmark selection, CPU profiling, allocation churn, retained memory checks, and performance budgets.
- Use with: `architecture-review`, `library-architecture`.

## 5. corpus-diagnostics
- Use for long-form canaries, width sweeps, script/font probes, extractor questions, and mismatch taxonomy.
- Use with: `browser-accuracy`, `research-log`.

## 6. packaging-release
- Use for dist shape, exports/entrypoints integrity, smoke testing, and release confidence.
- Use with: `demo-dogfooding`, `development-workflow`.

## 7. demo-dogfooding
- Use for editorial demo updates, rich line API exercise coverage, edge capture, and QA loops.
- Use with: `packaging-release`, `browser-accuracy`.

## 8. priorities-roadmap
- Use for next-work selection, priority scoring, dependency/risk sequencing, and not-now discipline.
- Use with: `research-log`, `architecture-review`.

## 9. research-log
- Use for decision memory: prior experiments, rejected hypotheses, durable findings, and proposal grounding.
- Use with: `priorities-roadmap`, `corpus-diagnostics`.

## 10. architecture-review
- Use for system-level diff review, contributor audit, dependency/risk analysis, escalation and approval quality.
- Use with: `benchmarks-profiling`, `library-architecture`.
