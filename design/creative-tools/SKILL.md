## Purpose

Provide structured guidance for creative production workflows across copy, imagery, vectors, documents, and final delivery packaging.

## Domain Coverage

This package now covers six connected capabilities:
- ad copy production and iteration,
- brand-consistent content production,
- PDF document operations,
- vector workflow automation,
- raster retouch pipeline,
- creative asset handoff.

## How to Use

1. Start with `self-diagnostic-protocol.md`.
2. Select a primary mini-skill.
3. Add adjacent mini-skills using `composition-protocol.md`.
4. Open corresponding references under `references/skills/`.
5. Open concrete examples under `examples/skills/`.
6. Use `resources/routing-guide.md` for multi-skill routing.
