# Self-Diagnostic Protocol

## Quick Integrity
Verify router, composition, manifest, catalog, routing guide, asset index files are readable.

## Activated Scope Checks
For selected skills, verify:
- token lifecycle ownership and change classification clarity
- adoption readiness, migration sequence, and exception process
- component API contracts and accessibility evidence
- framework mapping completeness
- documentation quality and governance gates

## Rejection Criteria
Reject or pause execution if any are true:
- token ownership unclear
- migration plan missing for major/breaking changes
- breaking changes undocumented
- adoption metrics weak or undefined
- accessibility or test evidence missing
