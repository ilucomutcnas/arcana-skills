# Skill Catalog

## Mini-Skills
1. foundations — primitives, semantic foundations, naming, and scale governance.
2. components — API contracts, states, variants, slots, and behavior models.
3. theming — light/dark/high-contrast/multi-brand mapping and inheritance.
4. accessibility — system accessibility governance and evidence expectations.
5. documentation — doc architecture, usage rules, migration/changelog integration.
6. governance — contribution workflow, RFCs, ownership, release operations.
7. review-audit — compliance scoring, prioritization, remediation reporting.
8. framework-mapping — token/component mapping into implementation frameworks.
9. design-token-governance — token lifecycle operations and release safety.
10. system-adoption-playbook — organizational rollout, enablement, metrics, exceptions.

## Relationship Notes
- `foundations` + `design-token-governance`: token creation plus lifecycle control.
- `governance` + `system-adoption-playbook`: policy + organizational execution.
- `documentation` supports, but does not replace, adoption playbook operations.
